EasyNET GSM data logger

Data logger industrial con comunicación GSM 2G/4G integrada para la adquisición, registro y transmisión remota de datos mediante Modbus, MQTT y HTTP REST.

Descripción

EasyNET es un data logger industrial diseñado para la adquisición, registro y transmisión remota de datos provenientes de dispositivos compatibles con Modbus RTU y Modbus TCP. Su configuración intuitiva permite integrar sensores e instrumentos sin necesidad de conocimientos de programación, facilitando una rápida puesta en marcha.

Además de las funciones de registro y gestión de datos, incorpora un módem GSM 2G/4G integrado, que le permite transmitir información de forma autónoma mediante protocolos estándar como MQTT y HTTP REST, garantizando una comunicación segura y eficiente con plataformas SCADA, sistemas IoT y aplicaciones en la nube.

EasyNET constituye una solución robusta y versátil para aplicaciones de monitoreo remoto, automatización industrial, gestión del agua, energía, infraestructura y control ambiental, proporcionando acceso continuo a información crítica para una gestión más eficiente de los activos.

Especificaciones técnicas

Puerto Ethernet 10/100 Mb/s
Puerto serie RS485 (1200–115200 bps)
Montaje Carril DIN (4 módulos)
Indicadores LEDs de señalización frontal
Dimensiones 90 × 70 × 60 mm
Temperatura de operación -20 °C a +60 °C
Certificación CE (EN 61000-6-2 / EN 61000-6-4)
Alimentación 10–40 VDC
Consumo < 1,5 W (promedio)
Interfaz serie 1 puerto RS485 mediante bornera
Módem integrado LTE Cat M1 con respaldo GSM/GPRS
Módulo SIM Ranura para tarjeta SIM integrada
